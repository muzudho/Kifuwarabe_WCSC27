# 📝 コマンド一覧

きふわらべい（Kifuwarakei）の **どうぶつしょうぎモード** で使えるコマンドを説明するぜ（＾▽＾）！

## 🎮 どうぶつしょうぎモードとは？

コンソール（黒い画面）で動く、対話型の将棋エンジンモードです。

**起動方法**:
```powershell
cd Bin\Release\net10.0
.\Grayscale.kifuwarakei.Engine.exe
```

起動後、**Enter キー** を押すと どうぶつしょうぎモードが始まります。

## 📖 基本コマンド

### `man`

**説明**: コマンド一覧・ヘルプを表示

**使い方**:
```
man
```

**応答**: 使用可能なコマンドの一覧が表示されます。

---

### `ky` (kyokumen)

**説明**: 現在の盤面を表示

**使い方**:
```
ky
```

**応答例**:

```
+--+--+--+--+--+--+--+--+--+

+--+--+--+--+--+--+--+--+--+
|v歩|v歩|v歩|v歩|v歩|v歩|v歩|v歩|v歩| 三
+--+--+--+--+--+--+--+--+--+
```

---

### `do <move>`

**説明**: 指し手を実行

**使い方**:
```
do 7g7f
do 7776FU
```

**指し手の形式**:
- **4文字**: 移動元と移動先 (例: `7g7f`)
- **6文字**: 移動元、移動先、駒種 (例: `7776FU`)

**駒種の略称**:
- `FU`: 歩
- `KY`: 香
- `KE`: 桂
- `GI`: 銀
- `KI`: 金
- `KA`: 角
- `HI`: 飛
- `OU`: 玉

**成駒**: 駒種の後に `N` (例: `7776FUN` = 成った歩)

**打つ**: `*` を使う (例: `*7f歩`)

---

### `undo`

**説明**: 1手戻す

**使い方**:
```
undo
```

---

### `set`

**説明**: 各種設定を変更

**使い方**:
```
set <設定名> <値>
```

**設定項目の例**:
- `set depth 10` - 探索深さを10に設定
- `set time 5000` - 思考時間を5秒に設定

---

### `@` (外部スクリプト実行)

**説明**: 外部のテキストファイルからコマンドを実行

**使い方**:
```
@ <ファイル名>
```

**例**:
```
@ test.txt
```

**注意**: 
元のREADMEには `Game/Command` フォルダー下のファイルを読むと記載がありますが、
現在のフォルダー構成では該当フォルダーがない可能性があります。

---

### `sasite`

**説明**: 指し手情報を表示

**使い方**:
```
sasite
```

**応答**: 合法手の一覧や、評価値などが表示されます（詳細は実装依存）。

---

### `kiki`

**説明**: 利き情報を表示

**使い方**:
```
kiki
```

**応答**: 各マスへの利きの状態が表示されます。

---

### `quit` / `exit`

**説明**: プログラムを終了

**使い方**:
```
quit
```
または
```
exit
```

---

## 🎯 どうぶつしょうぎ固有の機能

### 盤面サイズの変更

どうぶつしょうぎ（3x4盤）だけでなく、以下のサイズに対応しています：

- **3x4 盤**: どうぶつしょうぎ
- **5x5 盤**: 5五将棋
- **9x9 盤**: 本将棋

**注意**: 
- ビットボードは128bitなので、3x4盤～9x9盤の間で動作します
- 設定ファイル（Engine.toml）で盤面サイズを変更できる可能性があります

## 🧪 使用例

### 基本的な対局の流れ

```
# 盤面を表示
ky

# 7六歩を指す
do 7g7f

# 盤面を表示
ky

# 3四歩を指す
do 3c3d

# 合法手を表示
sasite

# 1手戻す
undo

# 利きを表示
kiki

# 終了
quit
```

### スクリプトファイルの例

**test.txt** (例):
```
ky
do 7g7f
do 3c3d
do 7f7e
ky
sasite
```

実行:
```
@ test.txt
```

## ⚙️ コマンドのカスタマイズ

### コマンドの追加方法

コマンドは `Sources/UseCases/Playing.cs` で実装されています。

新しいコマンドを追加する場合:

1. `Playing.cs` の該当箇所にコマンド処理を追加
2. ビルドしてテスト

**例** (簡略化):
```csharp
if (command == "mycommand")
{
	Console.WriteLine("My custom command!");
	return;
}
```

## 🐛 既知の問題

### バグ一覧

以下のバグが報告されています：

- ❌ **1段目でしか成らないバグ**: 2段目や3段目で成る処理が動かない
- ❌ **うさぎの1段目成らず**: どうぶつしょうぎで、うさぎ（歩）が1段目で成らない
- ❌ **世界一周バグ**: 駒が盤の端を超えて反対側に出現する

### しんでる機能

- ❌ **機械学習**: 3x4盤専用で動かなくなった
- ❌ **定跡**: 3x4盤専用で動かなくなった
- ❌ **成績管理**: 3x4盤専用で動かなくなった
